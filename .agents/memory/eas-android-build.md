name: EAS Android APK builds from this workspace
description: How to run eas-cli builds for artifacts/1inme-mobile from the Replit env (auth, gotchas, polling)
---

- Auth: `EXPO_TOKEN` secret authenticates eas-cli non-interactively (robot "SAYZIO", account **eefind** — not "sayzio"). Project: `@eefind/sayzio-mobile`, projectId `7d456b75-3a4b-4f59-95b1-369f0cb1ba77` (now in app.json).
- **Why the first init failed:** a placeholder `extra.eas.projectId` makes `eas project:init` think it's already linked, then GraphQL fails on "Invalid UUID appId". Remove the field first, then `project:init --non-interactive --force`.
- **expo-share-intent duplicate ShareExtension:** the plugin injects its own iOS appExtension; ANY manual `extra.eas.build.experimental.ios.appExtensions` ShareExtension entry makes `expo config` fatal ("more than one appExtensions"). Remove the manual block entirely — deduping to one still fails.
- **Git is blocked:** eas-cli's default VCS mode touches `.git/index.lock`, which the agent sandbox forbids. Always run with `EAS_NO_VCS=1`.
- **Upload exceeds bash timeout:** project archive is ~1.0 GB (monorepo, no `.easignore`), compress+upload ≈ 90s+. `nohup`'d children get reaped when the bash call ends — run the build via a registered validation workflow (`setValidationCommand` + `restart_workflow`) with `--no-wait`, then poll `eas build:view <id> --json` (calls flakily time out; wrap in `timeout 60`, retry).
- Preview profile = APK, signed with an EAS-generated remote keystore; production profile = AAB for Play Store.
- **How to apply:** future builds are just `EAS_NO_VCS=1 npx -y eas-cli build --platform android --profile preview --non-interactive --no-wait` from artifacts/1inme-mobile. Consider adding a `.easignore` to cut the 1 GB archive.
- **Dialer standalone (`sayzio-dialer-standalone`)**: project `@eefind/sayzio-dialer`, projectId `dac41f13-73e0-4fae-ad1b-0c686e37cc6b`, own eas.json (preview=APK, EAS-generated keystore). EAS archives from the WORKSPACE ROOT even with EAS_NO_VCS=1 (builder path `workingdir/build/sayzio-dialer-standalone`), so a `.easignore` inside the subproject is IGNORED — the effective one is the workspace-root `.easignore` (excludes **/node_modules, Laravel vendor/storage, etc.; cut archive 1.1 GB → 259 MB).
- **npm ci "Exit handler never called" on the EAS builder — TRUE root cause is the Replit package firewall**: lockfiles generated in this workspace record `resolved` URLs like `http://package-firewall.replit.local/npm/...`, unreachable from the EAS builder (ENOTFOUND) — npm 10 dies with the cryptic "Exit handler never called!"; downstream symptoms `expo: not found` / "Read app config" errors are just the failed install. Fix: `sed -i 's|http://package-firewall.replit.local/npm/|https://registry.npmjs.org/|g' package-lock.json` before building (re-check after any local npm install). Adding `"eas-build-pre-install": "npm install -g npm@11"` to package.json makes the builder print the real ENOTFOUND instead of the opaque crash — keep it.
- **Decoding EAS remote build logs**: fetch via GraphQL `POST https://api.expo.dev/graphql` with `Authorization: Bearer $EXPO_TOKEN`, query `{builds{byId(buildId:"..."){logFiles error{message}}}}`; the logFiles URLs are BROTLI-compressed JSONL (magic bytes `0b 48 49`; `pip install brotli`, decompress, each line is a JSON log record).
- **Free-plan build quota**: account eefind is on the Expo Free plan — limited Android builds/month; when exhausted, `eas build` fails with "This account has used its Android builds from the Free plan this month" (resets on the 1st). Check `build:list` for the newest finished APK instead of retrying.
- **project:init --force duplicates appExtensions**: re-running `eas project:init` (e.g. after switching accounts) can re-inject the expo-share-intent ShareExtension block into app.json, creating a duplicate → every `eas build` fails at "expo config --json exited with code 1" with ZERO output (SilentError swallowed). Diagnose by temporarily patching logCmdError in @expo/cli build/src/utils/errors.js to write the error to a file; fix = delete the whole extra.eas.build.experimental block.

- Installing npm packages inside Replit rewrites `package-lock.json` "resolved" URLs to `http://package-firewall.replit.local/npm/...`; EAS build workers cannot resolve that host and fail at INSTALL_DEPENDENCIES (ENOTFOUND). Before kicking a build, `grep package-firewall package-lock.json` and sed the URLs back to `https://registry.npmjs.org/` (integrity hashes stay valid).
