# Navigation and task context update

Personal creator earnings and payouts now live in Earnings, separate from Business finances (companies, invoices, recurring invoices, expenses, catalog, tax and ledger). CRM collects clients, leads, contacts and dialer; Work contains tasks, attendance, leave and vault. The shared desktop/mobile web rail and classic fallback menus are updated. The main mobile drawer mirrors the distinction, adding contacts and dialer to CRM and moving wallet, purchases and API usage into My purchases & usage. Existing route and permission gates are retained.

Tasks support up to 20 related Sayzio items. Paste a full URL from the configured Sayzio site, select a type, name it and optionally explain what needs doing. Types include links/pages, Minds, contacts, projects, invoices, events, files and other pages. Labels and context appear on the board and in board search. References can be removed and are covered by existing task permissions, revision conflict checks and activity history. URLs do not fetch or disclose destination data and do not grant access. These are manually connected references, not automatic dependency tracking or an all-resource search picker. Custom-domain links can be represented by their canonical Sayzio management URL.

Deployment requires the additive related_items JSON migration before serving the new task editor. No existing task data is rewritten. Installed main mobile apps require their normal distribution update.

Validation: mobile TypeScript and navigation route checks; Blade inline-script syntax; migration ordering with isolated PostgreSQL; task persistence, unsafe URL rejection, max count, stale revision, viewer edit denial, navigation ownership and permission tests. The page-render suites report existing output-buffer risky-test warnings; no assertion failures. Browser checks use disposable local records and verified a connected creator-profile reference survives reload, plus Earnings, Business and CRM category contents. Production deployment and physical-device checks were not performed.
